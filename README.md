# Ideando

Página web comercial de una sola página para Ideando, con regalos personalizados, velas aromáticas, etiquetas escolares y consultas preparadas para WhatsApp.

## Uso local

Abre `ideando.html` en Chrome o Edge. Las imágenes y fuentes de muestra necesitan conexión a Internet.

## Configurar WhatsApp

En `ideando.html`, reemplaza `51999999999` por el número comercial con código de país, sin espacios ni signos.
